clock 模块 = 时间源 + 刻度抽象 + 计时器注册表 + WFI 目标

外部统一用 core::time::Duration；内部热路径用 raw u64 ticks；换算在模块内(u128、无浮点)。

1 · 频率源 / 初始化
init(timebase) → Result<(),ClockError>ClockError::{NoTimebase, AlreadyInit}

DTB /cpus 的 timebase-frequency 由 main::probe 纯值注入，记录启动时刻 BOOT → 消除硬编码 10 MHz 假设。

2 · 单调时钟抽象
now() → InstantInstant::add / sub (Duration)elapsed() / elapsed_since()uptime() → Durationticks_to_duration / duration_to_ticks

Instant 是内部 u64 计数器刻度的薄包装；时间区间一律 Duration，回绕安全。

3 · tick 计数字（定时器中断次数）
tick()ticks()

trap 的 S-timer 分支每中断 tick() +1；ticks() 供 ENV_GET_TICKS 兼容（诊断用，非时间单位）。

4 · deadline 注册表（核心，全局最小堆）
reserve() → handlearm_at(handle, dl)cancel(handle)poll_due(now) → Vec<handle>next_deadline()

堆条目 = (deadline_ticks, handle) 纯数据，不持任务引用；NEXT_DEADLINE 原子镜像供锁外读。修复“队首检查漏唤醒”缺陷①。

5 · WFI / 武装目标
timer_interval_ticks()wfi_arm_delta()

100 ms 抢占量子由 timebase 派生；tickless：WFI 睡到最近 deadline、无则推远 —— 替代 TIMER_NEVER hack（缺陷③）。

功能如何被串起来：三条关键时序

启动 / 每次定时器中断

DTB probe → clock::init(timebase) → trap::init(arm timer_interval_ticks) → 每 S-timer 中断: clock::tick() → scheduler::unpark()(内含 poll_due) → 重武装下一周期。

任务睡眠生命周期

ENV_SLEEP(Duration) → scheduler::park: deadline_after(d) → reserve() → blocked 映射 insert → arm_at(handle,dl) → Running→Blocked{Park{wake_at}} → 到期: poll_due(now) → 按 handle 摘除 → Blocked→Starved 入就绪 → 恢复运行。

空闲核 tickless 休眠

wait(): 置睡眠位 → 复查队列 → wfi_arm_delta() → arm → WFI → 到期/IPI 唤醒 → unpark()(poll 唤醒到期者) → 清 SSIP → 循环。

唤醒机制仿真：最小堆 vs 旧队首检查
